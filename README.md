# claude-skills

Claude Code skills from [mrgoonie/claudekit-skills](https://github.com/mrgoonie/claudekit-skills) and [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (which also supplies `ui-styling`), kept in `.claude/skills/` so every Claude Code session started on this repo loads them.

To use them on your own machine instead: `cp -r .claude/skills/* ~/.claude/skills/`

Anthropic's own docx/pdf/pptx/xlsx skills from claudekit-skills are left out because their license doesn't allow redistribution; Claude has built-in versions of them.
